# 事件因子：SUE、PEAD 与反转

## 研究目标

复现财通证券"星火"多因子专题报告（十一）《在下跌中寻找惊喜，业绩超预期与反转因子的融合》，研究业绩超预期事件（PEAD）、公告后漂移与价格反转之间的关系，并把因子打包成可回测的月频选股策略。

## 关键结果

### 样本内（2009.12–2020.01，与研报一致）

| 指标 | 研报 | 复现 |
|---|---|---|
| SUE1 / SUE2 / SUE3 RankIC | 4.2% / 4.4% / 4.6% | 4.20% / 4.35% / 4.55% |
| L4D0 多头年化超额 | +11.78% | +11.23% |
| L0D4 空头年化超额 | −19.12% | −19.68% |
| 策略回测（多头 L4D0，月频） | — | 年化 +12.74%，超额 +188.75%（基准沪深300） |

"越及时越强"（SUE1→SUE2→SUE3 RankIC 单调上升）在聚宽数据上完整复现。

### 样本外（2021–2025）

因子**显著衰减、接近失效**：

- 因子层：RankIC 4.55% → 1.26%，T 值 10.83 → 1.67（统计上不显著），分组单调性崩坏。
- 策略层：年化超额 ~11.5% → ~1.6%，绝对收益转负（−1.25%），仅相对基准仍微正超额（+8.88%）。
- 归因：风格切换（小盘成长→大盘价值/高股息）+ 因子拥挤（研报公开后被广泛采用）+ 市场下行放大回撤。

这是诚实的样本外结论：多头选股能力消失、仅空头（避开最差股）残留微弱区分度，属因子生命周期正常现象。
